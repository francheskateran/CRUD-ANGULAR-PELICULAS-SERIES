# GUÍA PARA LA EJECUCIÓN DEL PROYECTO

Para hacer funcionar la aplicación en un entorno local, sigue esta secuencia de pasos ordenados desde la preparación del entorno hasta el arranque en el navegador.


## Instalar Angular CLI de forma global

npm install -g @angular/cli

## Instalar las dependencias del proyecto

npm install


Nota: Este comando leerá el archivo package.json e instalará automáticamente Angular Core, Router, Forms, RxJS y todas las herramientas de desarrollo necesarias dentro de la carpeta node_modules.

## Iniciar el servidor de desarrollo

ng serve --open
